# 참고 자료와 구조 결정

조사일: 2026-09-11

## 제공된 디자인

설치된 Code Agent Gauge 1.10.28의 앱 번들 메타데이터와 사용자가 제공한 세 화면을 참고했습니다. 번들에서 macOS 14 이상, 메뉴 막대 앱 설정을 확인했습니다. 앱 바이너리의 내부 로직을 추출하거나 이미지 자산을 재사용하지 않았습니다.

반영한 요소: 초록색 강조, 남은 비율의 원형 게이지, 둥근 카드, 리셋 카운트다운, 토큰 비교, 작은 갱신 상태 표시. 넓은 분석 화면 대신 560pt 메뉴 패널로 줄였습니다.

위 저장소는 제품 범위와 구조 비교에만 사용했습니다. 외부 소스 코드를 가져오거나 의존성으로 포함하지 않았습니다.

## 프로토콜의 근거

[공식 Codex App Server 문서](https://learn.chatgpt.com/docs/app-server)의 초기화, 계정 조회, 다중 한도, 토큰 요약 스키마를 기준으로 구현했습니다. 설치된 `codex-cli 0.148.0`에서 생성한 JSON Schema와 실제 읽기 응답도 확인했습니다.

서버의 사용량은 소진 비율이므로 남은 비율은 `100 - usedPercent`입니다. 값 없음은 0%와 다르게 처리합니다. reset 시간은 Unix 초 단위입니다. 토큰 조회는 선택적이며 실패가 한도 조회를 무효화하지 않습니다.

## 유지보수 원칙

1. 외부 패키지 없이 SwiftUI·AppKit·Foundation·CryptoKit 등 macOS 기본 프레임워크만 사용합니다.
2. UI는 네트워크 응답 구조와 직접 통신하지 않습니다. `UsageProvider`를 교체하면 데이터 소스를 바꿀 수 있습니다.
3. 표시는 서버가 반환한 값에 근거합니다. 누락한 정보를 샘플 값이나 추정치로 채우지 않습니다.
4. 샘플 모드는 실제 연결 모드와 분리하고 화면에 표시합니다.
5. 빌드와 실행은 프로젝트 안의 `dist`에서 처리합니다. 설치·자동 실행·배포는 별도 작업으로 남깁니다.
