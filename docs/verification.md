# 기본 구조 및 기간·초기화권 검증

검증일: 2026-09-11

환경: Apple Silicon, macOS 26.6.2, Swift 6.3.3 Command Line Tools, Codex CLI 0.148.0. 최소 지원 버전은 macOS 14로 선언했으며, 다른 OS 버전과 Intel Mac에서 직접 실행 검증하지는 않았습니다.

## 초기 기본 구조 결과

- 릴리스 빌드 성공. `dist/Cocount.app` 약 1.3MB, 실행 파일 약 867KB.
- 생성한 번들의 로컬 서명과 Info.plist 유효성 확인.
- 실제 계정으로 `--probe` 실행 성공 및 정상 종료. 주간 한도와 토큰 요약 응답 확인.
- 로컬 프로세스 테스트를 포함한 15개 자동 검증 통과.
- SwiftUI ImageRenderer로 라이트·다크 샘플 PNG 생성 후 직접 시각 확인.
- 실제 앱 UI에서 메뉴 패널·설정·독립 개발 창 확인.
- 다크 모드, 토큰 카드 숨김, 1분 갱신 설정이 화면에 적용됨을 확인.
- 샘플 모드에서 예시 표시·두 번째 한도 카드 확인. 실제 모드 복귀 시 서버 응답으로 교체 확인.
- 수동 새로고침 후 갱신된 한도 표시 확인.
- 조회 도중 종료 버튼 클릭 시 앱 종료 확인. 검증용 프로세스 잔류 없음.
- 검증 후 설정은 시스템 화면·5분 갱신·토큰 표시·실제 데이터 모드로 복원.

## 자동 검증 범위

다중 한도 우선순위, 다른 모델 한도 분리, 구형 응답과 기간 순서, null 비율, 퍼센트 범위, 지난 리셋 시각, 다양한 기간명, 미집계와 0의 구분, 64비트 토큰, null 토큰 요약, 실행 경로 오류, 분할 JSON 응답, 알림 무시, 오류 메시지 정제, 응답 제한 시간, EOF, 초기화와 지원하지 않는 서버 요청 거절을 검증합니다.

```bash
make test
```

잠자기 복귀 이벤트와 5분 간격의 장시간 연속 실행은 구현했지만, 이번 검증에서는 실제 잠자기 전환이나 장시간 안정성 시험을 수행하지 않았습니다.

## 기간·초기화권 업데이트 결과

- 릴리스 빌드 성공. 업데이트한 앱 번들은 약 1.7MB.
- 자동 검증 22개 통과. 남은 시간 링의 경계, 과거 두 기간 보관·직렬화, 조기 리셋, DST·연도 경계의 3주 달력, 하루 일부 구간, 초기화권의 권위 있는 총수와 생략된 상세 목록, 만료순 정렬·남은 비율 검증 추가.
- 실제 계정 `--probe`에서 기본 Codex 한도, 토큰 요약, 초기화권 목록 조회 성공.
- 실제 UI에서 초기화권 만료 일시와 각각의 남은 시간, 만료일 클릭 후 해당 날짜로 달력 이동 확인.
- 샘플 UI에서 지난 두 번째 기간 선택 시 달력 이동, 10월 만료일 선택 시 해당 날짜의 빨간 테두리 확인.
- 라이트·다크 샘플 화면을 렌더링하고 확인. Spark 모델 표시 없음.
- 실제 UI에서 본문 스크롤 후 초기화권 목록과 고정된 갱신 상태·종료 버튼 확인.
- 실제 과거 이력은 초기 실행 시 `기록 없음`. 샘플 이력이 실제 기록에 섞이지 않음을 화면에서 확인. 시간 경과 후의 실제 자동 이월은 단위 검증으로 확인했으며, 수주간 실사용 검증은 아직 수행하지 않음.

## 달력 내 과거 기간 표시 업데이트

- 현재·지난 1·지난 2 기간 하단 카드와 기록 안내 문구 제거.
- 현재 기간의 경과/남은 시간은 초록색, 과거 두 기간은 두 농도의 회색으로 구분.
- 날짜 도움말에 기간명과 시작·종료 시각 표시. 기존 달력 화살표로 과거 날짜 탐색.
- 릴리스 빌드 성공 및 라이트·다크 샘플 이미지에서 카드 제거와 기간 색상 구분 확인.

## 초기화권 영역 간소화

- 초기화권 제목과 총수, 전체를 감싸던 테두리 카드를 제거하고 개별 행만 표시.
- 릴리스 빌드 및 라이트 미리 보기에서 변경 확인.

## 보조 문구 간소화

- 남은 사용 한도 문구, 달력 기간 색상 범례 두 줄, 토큰 집계 안내, 푸터 갱신 주기 문구 삭제.
- 릴리스 빌드 및 라이트 미리 보기 확인. 만료일 범례와 실제 자동 갱신 기능은 유지.

## 초기화권 일별 블록 바

- 행 높이를 32pt로 축소하고 만료일을 M/d HH:mm 형식의 한 줄로 표시.
- 한 칸 24시간의 블록 배경과 부분 일수 채움 구현.
- 빌드, 라이트 미리 보기 확인 및 자동 검증 23개 통과.


## 파스텔 프리셋 업데이트

- 세이지·라벤더·스카이·피치·로즈 5개와 각 라이트·다크 모드 구현. 기존 영역별 색상 역할을 공통 토큰으로 전환.
- 상단 팔레트 메뉴에서 5개 모두 클릭 전환, 설정 선택기와 동기화 확인. 접근성 선택 상태와 테마명이 즉시 갱신됨.
- 별도 샘플 앱에서 라이트·다크 설정 화면을 직접 확인하고, 재실행 후 라벤더와 다크 모드 복원 확인.
- 릴리스 빌드, Core 검증 23개 통과. 10개 대시보드 렌더링 및 글자·배경 90개 조합의 4.5:1 이상 대비 확인.
- 팔레트 출처와 적용값·검증 범위는 [컬러 팔레트 문서](color-palettes.md) 참고.

## 오늘 로컬 토큰 추정

- 오늘 항목에만 로컬 추정치·추정 표시·작은 어제 대비 비율 추가. 어제와 그래프는 서버 집계 유지.
- 자동 검증 27개 통과: 누적 증가분, 반복 이벤트, 날짜 경계, 분기 상속 카운터, 카운터 감소, 0/미집계 비교, 파일 복사 중복, 캐시, 미완성 줄 재조회 포함.
- 실제 로컬 집계 probe 성공. 관측된 최초 조회 약 0.84초, 변경 없는 캐시 조회 0.01초 미만. 일부 기록 처리 플래그 확인, 추정치 도움말에 반영.

## 세이지 라이트 채도 보정

- Color Hunt의 크림·민트 조합을 참고해 세이지 라이트 팔레트만 교체했습니다. 주조색 `#95D2B3`, 바탕 `#F4FBF3`, 흰 카드, 강조색 `#247A58`로 회색기를 줄였습니다.
- 수정 전 소스와 비교해 나머지 9개 라이트·다크 팔레트와 공통 테마 로직이 그대로임을 확인했습니다.
- 릴리스 빌드 성공. 실제 SwiftUI 렌더링 확인 및 기본/보조 글자·강조·시간·달력·초기화권의 9개 글자/배경 조합에서 4.61:1 이상 확인.

## 한도 사용률 전환

- 기존 토큰 카드의 크기, 오늘·어제 수치 배치, 7일 막대그래프, 15분 간격 하단 그래프를 유지했습니다. 카드 제목으로 토큰/한도 전환, 기준 문구로 주간/5시간 전환, 날짜 막대로 해당일 시간대 선택이 가능합니다.
- 계정별 잔여율 관측 저장과 일별·시간별 추정 집계를 추가했습니다. 첫 관측, 기록 없음/0, 한도 종류 분리, 자정에 걸친 시간 비례 배분, 일별/시간별/15분별 합계 일치, 리셋, 잔여율 증가, 30분 초과 공백, 누락/비정상/만료 값, 중복·역순 관측, 100% 초과 누계, 직렬화·보관 기한, DST 23/25시간·92/100구간을 검증했습니다.
- `make test`: 전체 32개 검증 통과. `make app`: 릴리스 빌드와 로컬 서명 성공.
- 분리된 샘플 앱의 실제 SwiftUI 창에서 제목 클릭으로 토큰 → 한도 복귀, 5시간 기준 전환, 어제 날짜 클릭과 하단 시간대 수치 연동을 확인했습니다.
- 라이트·다크 렌더링을 기존 토큰 화면과 비교해 배치가 유지됨을 확인했습니다. [라이트](images/limit-usage-light.png), [다크](images/limit-usage-dark.png).
- 과거 이력 소급 집계는 제공하지 않습니다. 실제 장기간 누적과 잠자기 전환은 장시간 실사용 시험 대신 계산 경계 검증으로 확인했습니다.
- 업데이트한 실제 앱을 다시 실행해 최초 조회의 기록 없음 표시와 후속 정상 조회의 사용률 표시를 확인했습니다. 계정별 로컬 저장소에 관측 기록이 저장되는 것도 확인했습니다. 샘플 검증 앱은 종료했습니다.

## 기본 너비 30% 축소

- 패널 너비를 560pt → 392pt로 변경했습니다. 2배율 렌더링도 1120px → 784px로 정확히 30% 감소했으며, 샘플 화면 높이는 약 706pt → 676pt입니다.
- 외부 여백 16pt → 12pt, 카드 내부 여백 18pt → 14pt, 카드 모서리 20pt → 16pt로 조정했습니다. 게이지와 리셋 설명을 세로로 묶고 달력은 오른쪽에 유지했습니다.
- 제목·주요 수치·초기화권 글씨와 그래프 간격을 조정했습니다. 토큰 단위를 날짜 라벨 옆으로 옮겨 네 자리 만 단위 수치가 잘리지 않도록 했습니다.
- 라이트·다크 및 토큰 화면을 SwiftUI로 렌더링하고 확인했습니다. 설정의 네이티브 컨트롤은 ImageRenderer에서 지원되지 않으므로 별도 번들 ID의 샘플 앱에서 직접 확인했습니다.
- 실제 macOS 팝오버에서 설정, 라이트·다크, 컬러 프리셋 선택과 표시 동기화, 축소된 팔레트 팝오버, 토큰 표시 전환을 확인했습니다.
- `make app` 릴리스 빌드와 로컬 서명 성공, `make test` 기존 검증 32개 통과.

## 메뉴 패널 전환

- 상태바 버튼의 마우스 누름 시점에 열기·닫기를 처리합니다. 최초 클릭 전에 SwiftUI 뷰를 구성하고, 패널 표시 후 필요한 데이터 갱신을 시작합니다.
- 열기 0.14초 ease-out, 닫기 0.10초 ease-in 페이드를 적용했습니다. AppKit의 위치 지정과 transient 닫기 요청을 유지하며, 이전 애니메이션 완료 콜백이 다시 열린 패널을 닫지 않도록 전환 번호를 확인합니다.
- macOS의 동작 줄이기가 켜져 있으면 애니메이션 없이 표시·닫기를 처리합니다.
- `make app` 경고 없는 릴리스 빌드와 로컬 서명 검증 성공. `make test` 기존 Core 검증 32개 통과. 실행 중이던 앱을 종료하고 새 빌드에서 실제 대시보드 표시를 확인했습니다.
- UI 자동화 도구가 숨겨진 메뉴 앱을 다시 활성화하거나 창 없음 오류를 반환하여, 상태바 연속 클릭·닫힘 직후 상태와 프레임별 전환 시간은 직접 검증하지 못했습니다. 동작 줄이기 설정과 다른 macOS 버전에서의 실행도 별도 검증하지 않았습니다.

## 성능·저장 공간 최적화

- Core 36개와 UsageStore 4개, 총 40개 검증 통과. 증분 로그 읽기·재작성 감지·미완성/큰 줄·취소·날짜 경계, 유휴 관측 압축·집계 일치, 계정별 이력 복원, 불필요한 토큰 조회 생략과 갱신 중 모드 전환을 확인했습니다.
- 반복 릴리스 빌드·로컬 서명·Info.plist 검증 성공. 라이트·다크·토큰 렌더링과 실제 UI의 카드/한도 기준/날짜 전환 확인 후 최종 앱을 재시작했습니다.
- 프로젝트 용량 약 528MB → 85MB. 합성 벤치마크 중앙값에서 추가 로그 처리 220ms → 2ms, 대량 그래프 집계 924ms → 111ms. 측정 조건과 저장량·한계는 [성능 점검 보고서](performance.md)에 기록했습니다.

## 토큰·한도 카드 전환 캐시

- 실제 `UsageStore`에 요청 횟수를 기록하는 공급자와 임시 로그를 연결한 12개 검증을 통과했습니다.
- 최근 토큰 데이터가 있을 때 토큰/한도 카드를 20회 왕복해도 추가 서버 요청·로컬 집계·로딩 표시가 발생하지 않았고, 기존 추정값을 유지했습니다.
- 한도만 조회한 후에도 같은 계정의 토큰 결과를 유지하며, 토큰 조회 시각은 한도 갱신과 분리합니다. 기본 5분 경계에서 한 번 다시 조회하고 추가 로그만 읽는 것을 확인했습니다.
- 갱신 중 전환, 카드 숨김/복원, 수동 새로고침 병합, 계정 변경/식별자 없음, 부분 실패/미지원 토큰, 실패 후 재시도 간격, 자정·시계 역행·주기 변경, 샘플 모드의 취소·캐시 초기화를 검증했습니다.
- 이 검증은 모의 서버와 합성 로그를 사용했으며 실제 계정에 대한 반복 네트워크 요청은 수행하지 않았습니다.
